# 🌍 Travel Platform

A full-stack travel platform built from scratch using modern web technologies.

## 🛠️ Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- TypeScript

### Database
- PostgreSQL
- Prisma

## 🏗️ Architecture

Next.js
   ↓
REST API
   ↓
NestJS
   ↓
Prisma
   ↓
PostgreSQL

## 🚀 Features

- Countries & Cities
- Destinations
- Hotels
- Tours
- Search & Filters
- Reviews & Ratings
- Favorites
- Authentication
- User Profile
- Admin Dashboard
